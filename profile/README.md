# Pairwise

Pairwise helps teams hire specialized engineers and staff project work. We score and shortlist candidates against the real requirements of a role, and we also run sourcing as a service when you want help filling seats.

[pairwise.ai](https://pairwise.ai)

## Public repositories

- [pairwise-mcp-skills](https://github.com/Pairwise-Technologies/pairwise-mcp-skills). Connect Claude, ChatGPT, Cursor, and other assistants to your Pairwise account, then ask about jobs, candidates, and evaluations in plain language.

More public repositories will show up here as they are ready to use.

## Connect your assistant

The MCP server for Pairwise customers is at `https://mcp.pairwise.ai/mcp`. The repository above has setup steps for Claude, ChatGPT, Cursor, Grok, and others. You sign in with your Pairwise account. You do not need an API key.

Creating or changing records still happens in the Pairwise web app.
